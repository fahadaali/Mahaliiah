# منصة المحلية · mahalliah

منصة تشغيلية لإدارة ومتابعة امتثال مجموعة شركات **المحلية**: التراخيص والسجلات، إقامات الموظفين،
المركبات، والمنصات والأنظمة — مع تعديل حي للبيانات، عدّاد انتهاء يتناقص فعلياً مع الأيام،
استيراد/تصدير Excel مع رفض التكرارات، ومصادقة وأدوار.

## المزايا
- **بيانات قابلة للتعديل بالكامل** (أشخاص، شركات، أرقام، تواريخ) عبر واجهة تفاعلية.
- **عدّاد حي**: المدد المتبقّية تُحسب لحظياً من التاريخ الفعلي وتتناقص مع الوقت.
- **استيراد/تصدير Excel** مع **رفض التكرارات** (رقم الإقامة/السجل التجاري/الترخيص/اللوحة…) وبيان سبب رفض كل صف.
- **مصادقة Cloudflare Access** + أدوار: مسؤول / محرّر / مطّلع.
- **تنبيهات انتهاء** (داخل اللوحة + بريد اختياري عبر مهمة Cron يومية).
- **سجل تدقيق** لكل إضافة/تعديل/حذف/استيراد.
- **إرفاق وثائق** (صور/PDF) لكل سجل عبر Cloudflare R2.
- **دعم التقويم الهجري** عرضاً بجانب الميلادي.

## البنية التقنية
| الطبقة | التقنية |
|---|---|
| الاستضافة والـAPI | Cloudflare Workers + Hono |
| قاعدة البيانات | Cloudflare D1 (SQLite) |
| المرفقات | Cloudflare R2 |
| المصادقة | Cloudflare Access (JWT) |
| الواجهة | HTML/CSS + JavaScript (وحدات ES) — بلا خطوة بناء |
| Excel | SheetJS (مضمّنة محلياً) |

## الهيكل
```
src/               خلفية Worker (Hono): مصادقة، أدوار، CRUD، استيراد/تصدير، مرفقات، تنبيهات
  index.ts         نقطة الدخول والمسارات + مهمة Cron
  auth.ts          المصادقة و RBAC
  access.ts        التحقّق من JWT الخاص بـ Cloudflare Access
  entities.ts      تعريف الكيانات (يقود CRUD والفرادة والاستيراد)
  crud.ts          عمليات CRUD + الاستيراد/التصدير
  dedup.ts         منطق رفض التكرار
  validate.ts      تطبيع الحقول
  attachments.ts   مرفقات R2
  alerts.ts        حساب التنبيهات + بريد Cron
public/            الواجهة (تُخدَم كملفات ثابتة)
  index.html, base.css, app.css
  js/              وحدات: main, dashboard, entity, admin, api, store, util
  vendor/          SheetJS
migrations/        مخطط D1 (0001) + بذرة البيانات الحالية (0002)
scripts/           build_seed.py (توليد البذرة) + smoke.sh
test/              اختبارات المنطق (vitest)
legacy/            لوحة العرض الثابتة السابقة (أرشيف)
```

## التشغيل والنشر
- النشر على Cloudflare (D1/R2/Access): راجع `DEPLOY.md`.

```bash
npm install
npm run db:migrate:local   # قاعدة محلية + بذرة
npm run dev                # http://127.0.0.1:8788
npm test                   # اختبارات المنطق
```

> **ملاحظة خصوصية**: البيانات تشمل أسماء وأرقام إقامات؛ الوصول محميّ بـ Cloudflare Access
> ولا يُفتح إلا للبُرد المصرّح بها في سياسة Access.
