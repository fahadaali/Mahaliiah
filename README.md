# لوحة قيادة المحلية · mahalliah Dashboard

لوحة قيادة تفاعلية لمتابعة الامتثال لمجموعة شركات **المحلية (mahalliah)**، مبنية من بيانات
المتابعة المرفقة (التراخيص والسجلات، إقامات الموظفين، المركبات، المنصات والأنظمة).

## التشغيل
افتح ملف `index.html` مباشرة في المتصفح — لا يحتاج خادماً أو اتصال إنترنت (البيانات
مضمّنة داخل `data/data.js`).

## المكوّنات
- **مؤشرات أداء (KPIs):** أعداد التراخيص والإقامات والمركبات والمنصات + ما هو قريب الانتهاء/منتهٍ.
- **فلاتر تفاعلية:** الشركة/المنشأة، الحالة (ساري/قريب الانتهاء/منتهٍ)، نافذة الاستحقاق
  (30/60/90/180 يوم)، وبحث نصي. كل الفلاتر تُحدّث المخططات والجداول فوراً.
- **مخططات:** توزيع حالة الإقامات (حلقي)، السجلات حسب الشركة، حالة المركبات
  (الاستمارة/الفحص)، الخط الزمني لانتهاء الإقامات خلال 12 شهراً.
- **قائمة الأولويات:** العناصر قريبة الانتهاء خلال 90 يوماً مرتّبة تصاعدياً.
- **جداول تفصيلية** بتبويبات قابلة للفرز لكل فئة.

## الهوية البصرية
الألوان مستمدة من شعار المحلية: الأخضر الزيتوني الداكن، الكريمي الفاتح، والأخضر الليموني،
مع ألوان حالة مرتبطة (أخضر/كهرماني/أحمر) للدلالة على السريان والاستحقاق والانتهاء.

## البيانات
- تاريخ المرجع للحسابات: **2026-06-28**.
- التواريخ الهجرية في أوراق التراخيص والمركبات محوّلة آلياً إلى الميلادي.
- التحديث: شغّل `scripts/build_data.py` لإعادة توليد `data/data.json` و`data/data.js` من ملف الإكسل.

## الملفات
```
index.html        # واجهة اللوحة

assets/logo.jpeg  # الشعار
scripts/build_data.py  # سكربت توليد البيانات من الإكسل
```
